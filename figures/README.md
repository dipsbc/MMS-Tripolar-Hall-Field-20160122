# Figure outputs

Store publication outputs using stable names such as:

- `Figure_1_overview_VDF.pdf`
- `Figure_2_relations.pdf`
- `Figure_S1_geometry.pdf`
- `Figure_S2_hodograms.pdf`
- `Figure_S3_multispacecraft.pdf`
- `Figure_S4_ohms_law.pdf`

Figures are outputs, not replacements for the numerical source data in
`data/derived/`.
