# Open Research: Data and Software Availability

## Manuscript-ready statement (replace all TBD fields)

Level-2 Magnetospheric Multiscale (MMS) magnetic-field, electric-field,
particle, and ephemeris data used in this study are publicly available from the
MMS Science Data Center at https://lasp.colorado.edu/mms/sdc/public/. The search
criteria are MMS1–MMS4, 22 January 2016, with the principal burst-mode interval
07:18:44–07:18:53 UT and the coordinate-analysis interval
07:18:36.860–07:19:00.920 UT. The products include FGM burst magnetic fields,
EDP burst electric fields, FPI/DIS and FPI/DES Level-2 moments, FPI/DIS ion
distributions, and MEC survey ephemerides. Exact CDF filenames, versions,
checksums, derived figure-source data, and version **TBD** of the analysis and
visualization code are preserved at **TBD REPOSITORY** under **TBD DOI**. The
derived data are released under CC BY 4.0 and the code under the MIT License.
The development version of the code is available at **TBD PUBLIC DEVELOPMENT
URL**. No registration is required to access the archived derived data or code.
