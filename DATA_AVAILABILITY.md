# Open Research: Data and Software Availability

Level-2 MMS1-MMS4 data used in this study are publicly available from the
[NASA Space Physics Data Facility (SPDF)](https://spdf.gsfc.nasa.gov/pub/data/mms/).
The exact source-file names, versions, and direct download links are provided
in the archived source-data manifest. Version 1.0.0 of the analysis code,
processed data, and supporting metadata is archived in
[Zenodo](https://doi.org/10.5281/zenodo.22044345) (Budhathoki & Qiu, 2026), with
the continuing development version available from the
[project GitHub repository](https://github.com/dipsbc/MMS-Tripolar-Hall-Field-20160122).
The analysis code is released under the MIT License, and the derived data and
documentation are released under the CC BY 4.0 license.
